# Generated OpenAPI contract

`star-dust-v1.json` is the machine-readable contract exported from the
Swashbuckle endpoint implemented by the ASP.NET Core application.

Run the following command from the repository root to refresh this contract
and the NSwag TypeScript client together:

```bash
./scripts/generate-api-client.sh
```

Do not edit the JSON snapshot manually. Controller metadata and Swagger
configuration are its source; `OpenApiContractTests` protects important
requiredness, operation-name, schema, and media-type behavior.
